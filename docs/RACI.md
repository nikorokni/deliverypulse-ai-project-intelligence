# Stakeholder RACI

| Activity | Product Manager | Project Manager | Engineering Manager | Data Lead | Sponsor |
|---|---|---|---|---|---|
| Product outcomes | A/R | C | C | C | I |
| Roadmap and scope | A/R | C | C | I | I |
| Integrated delivery plan | C | A/R | C | I | I |
| Capacity plan | C | C | A/R | I | I |
| Risk register | C | A/R | C | C | I |
| Confidence model | A | C | C | R | I |
| Release trade-off | R | C | C | C | A |
| Stakeholder update | A | R | C | I | I |

**R** Responsible · **A** Accountable · **C** Consulted · **I** Informed

## Communication plan

| Audience | Information | Cadence | Format | Owner |
|---|---|---|---|---|
| Delivery team | Blockers, capacity, dependencies | Twice weekly | Risk triage | Project Manager |
| Product leadership | Confidence, scope, outcomes | Weekly | Decision brief | Product Manager |
| Executive sponsor | Decision required, impact, recommendation | By exception | One-page escalation | Product Manager |
| Engineering leads | Flow metrics and capacity | Weekly | Delivery review | Engineering Manager |
